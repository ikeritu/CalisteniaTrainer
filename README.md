# Calistenia Trainer v1.4 RC — Pre-beta

Esta versión cierra el trabajo de desarrollo pendiente de las fases 1–8 antes de la beta física.

## Integrado
- Programa de 8 semanas y alternancia A/B.
- Progresiones adaptativas y seguridad/dolor.
- Animaciones SVG específicas para los ejercicios actuales (esquemáticas, no vídeo real).
- Tiempo total de sesión y tiempo del ejercicio.
- Botón de ejercicio anterior.
- Pausa/reanudación.
- Dashboard de progreso: 6 semanas, calendario, evolución por ejercicio, PR, volumen de bíceps.
- Exportación JSON y CSV.
- Hitos discretos.
- Modo oscuro, modo parque, botones grandes.
- Wake Lock, vibración y sonido cuando el navegador/dispositivo los soporta.
- PWA offline.

## Pendiente que NO puede cerrarse sin dispositivo real
- Validación de instalación PWA en Xiaomi/Android.
- Validación real de Wake Lock, vibración y sonido.
- Validación de legibilidad a pleno sol y uso con una mano/manos sudadas.
- Validación real del service worker/offline tras instalar desde HTTPS.
- Beta de entrenamiento de 2 semanas.
